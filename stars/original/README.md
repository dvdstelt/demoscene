# Original STARS files go here

This folder is where the remake looks for `STARS.EXE` (1,224,140 bytes, sha256
`148aa9240f6a29a5678a0812cf295a38039560f05d26dcfae8c829f8cafa97fc`) from the final release of *STARS: Wonders of
the World* by NoooN (September 1995). It is not part of this repository: it belongs to its authors. Get
[`nooonstf.zip`](https://files.scene.org/view/demos/groups/nooon/nooonstf.zip) from scene.org and unpack it here;
it holds `STARS.EXE`, `STARS.NFO` and `FILE_ID.DIZ`. The party version (`nooon_st.zip` in scene.org's Assembly '95
folder) is a different executable; the remake checks that it has this one.

Everything in this folder except this README is ignored by Git.
