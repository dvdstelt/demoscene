# The original STARS release

This folder holds the original release of *STARS: Wonders of the World* by NoooN (the final release of September 1995), as it is in [`nooonstf.zip`](https://files.scene.org/view/demos/groups/nooon/nooonstf.zip) on scene.org, without the `scene.org` banner that scene.org adds to its downloads. The remake reads its files from here at run time, and the release downloads include them. They belong to their authors ([NOTICE.md](../../NOTICE.md)); the repository's license does not cover them.

The remake reads `STARS.EXE` (1,224,140 bytes, sha256 `148aa9240f6a29a5678a0812cf295a38039560f05d26dcfae8c829f8cafa97fc`). The release also holds `STARS.NFO` and `FILE_ID.DIZ`. The party version (`nooon_st.zip` in scene.org's Assembly '95 folder) is a different executable; the remake checks that it has this one.
