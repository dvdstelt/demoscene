# The original 303 release

This folder holds the original release of *303* by Acme (X'97, 1997), as it is in [`acme_303.zip`](https://files.scene.org/view/demos/groups/acme/demos/acme_303.zip) on scene.org. Both remakes read its files from here at run time, and the release downloads include them. They belong to their authors ([NOTICE.md](../../NOTICE.md)); the repository's license does not cover them.

The remakes read `303.EXE`, `MUSTARD.PAK`, `GARLIC.PAK`, `KETCHUP.PAK`, `ALEX.LZW`, `HARL.LZW`, `VS.LZW` and `PARANOID.LZW`. The release also holds `303.NFO`, `FILE_ID.DIZ` and `Skynet.nfo`, an advert of the Skynet FTP site that was added when the release passed through it.
