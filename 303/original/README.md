# Original 303 files go here

This folder is where the remakes look for the original release of *303* by Acme. The files are not part of this
repository: they belong to their authors. Get them from scene.org with

```
scripts/fetch-originals.sh 303        # Linux / macOS
powershell -ExecutionPolicy Bypass -File scripts\fetch-originals.ps1 303   # Windows
```

or copy them here yourself: `303.EXE`, `MUSTARD.PAK`, `GARLIC.PAK`, `KETCHUP.PAK`, `ALEX.LZW`, `HARL.LZW`, `VS.LZW`,
`PARANOID.LZW`. Everything in this folder except this README is ignored by Git.
